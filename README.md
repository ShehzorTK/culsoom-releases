# CULsoom: downloads

Download the latest CULsoom build from the [Releases page](../../releases/latest).

1. Open **Releases** and pick the newest version.
2. Under **Assets**, download the file for your computer.
3. Open it and follow the prompts. On a Mac, right-click the app and choose Open the first time.

This repo only holds builds. It contains no source code, photos or client material.
